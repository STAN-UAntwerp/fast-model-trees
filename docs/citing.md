# Citing

If you use this package in your research, please cite the PILOT paper, and the RaFFLE
paper when you use RaFFLE.

> Raymaekers, J., Rousseeuw, P. J., Verdonck, T., & Yao, R. (2024). Fast linear model
> trees by PILOT. *Machine Learning*, 1–50. <https://doi.org/10.1007/s10994-024-06590-3>

```bibtex
@article{raymaekers2024pilot,
  title={Fast linear model trees by PILOT},
  author={Raymaekers, J. and Rousseeuw, P.J. and Verdonck, T. and Yao, R.},
  journal={Machine Learning},
  pages={1--50},
  year={2024},
  doi={10.1007/s10994-024-06590-3}
}
```
